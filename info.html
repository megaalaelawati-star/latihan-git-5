Halaman Info

Website sederhana ini dibuat untuk latihan pembuatan halaman web berbasis proyek tahun 2025. Tujuannya adalah mengenal dasar-dasar HTML dan CSS serta membangun struktur halaman yang rapi.

Beberapa informasi penting yang bisa ditemukan di website ini antara lain:

  • Profil pribadi
  • Data akademik / riwayat
  • Informasi umum
  • Kontak

Dengan adanya halaman ini, diharapkan bisa menjadi dasar untuk membuat website yang lebih kompleks di masa depan.
